# Fashion Image Classification

A simple Deep Learning practical that uses **TensorFlow/Keras** to classify fashion product images into 10 categories.

## Categories

* T-shirt/Top
* Trouser
* Pullover
* Dress
* Coat
* Sandal
* Shirt
* Sneaker
* Bag
* Ankle Boot

## Technologies

* Python
* TensorFlow/Keras
* NumPy
* Matplotlib
* Fashion MNIST

## Model

The neural network uses:
**Input → Hidden Layer (64 neurons) → Output (10 classes)**

The model is trained for 3 epochs and evaluated using test accuracy.

## Business Use

The system can help e-commerce companies automatically categorize product images, reducing manual classification work.
